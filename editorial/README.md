# Ton mot de la semaine

Pour ajouter un édito au prochain article du lundi : crée (ou modifie) le fichier `editorial/next.md`
dans ce dossier, directement sur GitHub (bouton « Add file » → « Create new file »), avant lundi 7 h.

- Texte simple : un paragraphe par bloc, séparés par une ligne vide (pas de HTML, il est affiché tel quel).
- Le lundi, le robot le place en tête de l'article et de la newsletter, puis le range dans
  `editorial/archive/<semaine>.md`.
- Pas de fichier `next.md` (ou fichier vide) : l'article part sans édito.
